第一次使用？設定管理密碼
  1. 按下面的「產生管理密碼」，再複製及儲存到你自己的密碼管理器。
  2. 在另一個分頁開啟 Cloudflare，選 Workers & Pages → psyc-thesis-hk-staging-api → Settings。
  3. 找到 Variables and Secrets，編輯已有的 ADMIN_TOKEN，類型選 Secret，貼上剛才產生的密碼，再按儲存／Deploy。
  4. 返回本頁，把同一個密碼貼到上面的登入欄。

請只編輯 ADMIN_TOKEN。DRAW_SECRET 用於抽獎資格驗證，請保留原值。管理密碼請自行保存，不要貼到聊天或 GitHub。

下載後怎樣使用

  • 研究答案可用 Excel、SPSS 或 R 開啟；中文編碼為 UTF-8。
  • 同一參加者會有多行。人數按不同的 participant_code 計算。
  • type=main 是主要圖像試次；attention 是注意力試次。valid_questionnaire 是有效問卷標記。
  • 空白評分代表該詞沒有被顯示作評分，保留為缺失值。
  • 如見到「系統測試勿分析」，先找該行的 participant_code，再排除這個代碼的全部行。
  • 抽獎檔案只有電話，請分開保管。試測與正式資料亦應分開分析。
